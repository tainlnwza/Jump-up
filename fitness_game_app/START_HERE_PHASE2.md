# Phase 2 - เริ่มที่นี่!

## 🚀 สิ่งที่ต้องทำตอนนี้

### 1. ติดตั้ง Blender (15 นาที)

ดาวน์โหลด: https://www.blender.org/download/
- เลือก Windows / Mac / Linux
- เวอร์ชัน 4.0 ขึ้นไป
- ติดตั้งตามปกติ
- เปิดทดสอบว่าใช้งานได้

### 2. เปิดไฟล์ Monster Model

ไฟล์ที่ต้องใช้อยู่ที่: `D:\MB_10001\`
- MB_10001.fbx (monster model)
- MB_T_20001.png (texture)
- MB_T_20001_S.png (specular)
- lvguang2.png (emission)

### 3. เริ่มทำ Blender Rigging

📖 **เปิดคู่มือ:** `docs/BLENDER_RIGGING_GUIDE.md`

ขั้นตอนคร่าวๆ:
```
1. Import FBX model
2. สร้าง Armature (bones)
3. Weight Paint (เชื่อม mesh กับ bones)
4. สร้าง 5 animations
5. Export เป็น FBX ใหม่
```

⏱️ **เวลาที่ใช้:** 6-9 ชั่วโมง (ครั้งแรก)
